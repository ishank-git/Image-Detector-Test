# VeritasAI - Deep Forensic & AI Image Authenticity Detector

VeritasAI is an advanced, offline-first image forensic analysis suite engineered to distinguish authentic photographic camera captures from AI-generated imagery (Stable Diffusion, Midjourney, DALL-E, Flux, GANs, etc.) and synthetic image manipulation.

---

## 🔍 Forensic Analysis Pipeline

Rather than relying purely on brittle black-box classifiers that degrade on newly released models, VeritasAI implements a multi-spectrum forensic physics pipeline:

1. **2D Fast Fourier Transform (FFT) Power Spectrum:**
   - Detects periodic harmonic lattice spikes generated by convolutional upsamplers and latent autoencoder decoders (e.g. 8x VAE in latent diffusion architectures).
   - Measures azimuthal high-to-mid frequency energy ratios against natural optical $1/f^\alpha$ power-law decay.
2. **Error Level Analysis (ELA):**
   - Resaves images across a calibrated 90% JPEG quality boundary to identify localized compression anomalies.
   - Flags synthetic texture homogeneity and boundary inconsistencies typical of composite inpainting.
3. **Sensor Noise (PRNU) Residual Analysis:**
   - Extracts high-frequency micro-texture using spatial filtering.
   - Evaluates silicon Photo-Response Non-Uniformity (PRNU) and photon shot noise dispersion across image tiles.
   - Differentiates natural Poisson-Gaussian sensor noise from synthetic hyper-smooth patches.
4. **Optical Chromatic Aberration & Color Gradient Correlation:**
   - Analyzes transverse chromatic aberration (TCA) across RGB channels.
   - Real glass optics naturally disperse wavelengths at lens peripheries; AI models correlate color channels synthetically.
5. **Metadata & Digital Provenance Inspector:**
   - Deep inspection of EXIF hardware camera tags (Make, Model, Lens, Shutter Speed, ISO).
   - Automatic extraction of PNG text chunks, AI software tags (`Automatic1111`, `ComfyUI`, `Midjourney`), embedded generation prompts, seeds, and C2PA Content Credentials manifests.

## 🚀 Quick Start

### 1. Requirements
- Python 3.10+ (tested on Python 3.14)
- Packages: `fastapi`, `uvicorn`, `numpy`, `pillow`, `scipy`, `python-multipart`

### 2. Installation
```powershell
pip install -r requirements.txt
```

### 3. Run the Application
```powershell
python run.py
```
Open your browser at **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.

---

## 🧪 Testing Benchmarks

Run the automated verification suite:
```powershell
python test_detector.py
```

The app also comes with built-in instant test benchmarks directly accessible on the web UI:
- **Load AI Diffusion Sample**: Tests synthetic upsampler lattice detection and prompt metadata extraction.
- **Load Real Camera Photo Sample**: Tests camera hardware EXIF verification, sensor PRNU noise, and optical chromatic dispersion.

## 🛡️ API Endpoints

- `POST /api/analyze`: Multipart file upload returning full forensic metrics, visual overlays (base64 heatmaps), and calibrated verdict.
- `POST /api/analyze-sample/{filename}`: Runs analysis on bundled benchmark samples.
- `GET /api/samples`: Lists available test benchmarks.
- `GET /api/health`: Health status.
